# SdA 1 — El motor de FinanzApp

**Materia:** Programación y Computación · 2º Bachillerato
**Unidad:** A.1. Lenguajes de programación
**Duración:** 12 sesiones (12 h)

Programa de consola en Python que registra ingresos y gastos, los clasifica por
categorías y guarda los datos en disco. Se construye de forma **estructurada**
(procedimental), usando funciones y persistencia en archivos.

## Contenido de la carpeta

| Archivo | Sesión | Contenido |
|---------|:------:|-----------|
| `01_basicos.py` | 1 | Tipos, variables, constantes, operadores, comentarios, `input`/`print` |
| `02_expresiones.py` | 2 | Operadores y expresiones aplicadas (porcentajes, redondeo, casting) |
| `03_condicionales.py` | 3 | `if / elif / else` |
| `04_bucles.py` | 4 | `while`, `for`, `break`, `continue` |
| `05_retos.py` | 5 | Retos integradores de control de flujo |
| `06_listas.py` | 6 | Listas y tuplas |
| `07_diccionarios.py` | 7 | Diccionarios, conjuntos y estructuras anidadas |
| `08_funciones.py` | 8 | Funciones y reutilización de código |
| `09_modulos.py` | 9 | Módulos de la biblioteca estándar e introducción a archivos |
| `10_archivos.py` | 10 | Persistencia en CSV y JSON con manejo de errores |
| `finanzapp.py` | 11 | **Producto final** integrado (menú + funciones + persistencia) |
| `movimientos_ejemplo.csv` | — | Datos de ejemplo |

## Cómo ejecutar

```bash
python3 01_basicos.py
python3 finanzapp.py
```

Requiere Python 3.8 o superior. No usa dependencias externas.
